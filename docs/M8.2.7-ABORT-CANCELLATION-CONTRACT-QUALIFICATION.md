## Upstream authority

Pinned AstraVector server blob:

```text
07afff94c4f3825ec953df55cd407ed7c653151a
```

The public facade contract is:

```text
AbortLogicalDocumentIngestion(
  ingestion_session_id,
  reason
) -> (
  ingestion_session_id,
  status
)
```

Pinned server behavior is state-sensitive:

```text
ACTIVE      -> mutate to ABORTED and return ABORTED
ABORTED     -> return ABORTED again (idempotent success)
FINALIZING  -> FAILED_PRECONDITION: INGESTION_SESSION_FINALIZING
COMPLETED   -> FAILED_PRECONDITION: INGESTION_SESSION_COMPLETED
FAILED      -> FAILED_PRECONDITION: INGESTION_SESSION_FAILED
EXPIRED     -> FAILED_PRECONDITION: INGESTION_SESSION_EXPIRED
not found   -> NOT_FOUND: INGESTION_SESSION_NOT_FOUND
state race  -> ABORTED: INGESTION_SESSION_STATE_CHANGED
```

## AstraIndexator contract

The gRPC adapter must:

- use generated protobuf and generated `AstraVectorIngestionFacadeStub`;
- send the exact ingestion session identity and non-blank reason;
- preserve configured metadata and finite deadline;
- reject an acknowledgement for another ingestion session;
- map `ABORTED` response state without inventing counters unavailable on the wire.

## Mutating-RPC ambiguity rule

Abort is a mutation. The following transport outcomes do not prove whether the remote abort committed:

```text
DEADLINE_EXCEEDED
UNAVAILABLE
ABORTED / INGESTION_SESSION_STATE_CHANGED
```

They therefore classify as:

```text
RECONCILE_STATUS
```

A caller must inspect the existing ingestion session before deciding whether any further mutation is safe.

Known terminal `FAILED_PRECONDITION` states and all unknown failures are fail-closed as `PERMANENT_FAILURE` at this wire-policy boundary.

This operation-specific rule intentionally overrides the generic transport intuition that `UNAVAILABLE` can simply be retried: a mutating call can have committed remotely before the connection was lost.

## Boundary

M8.2.7 does **not** implement durable user/job cancellation orchestration. It does not own:

- PostgreSQL cancel checkpoints;
- worker fencing or lease revocation;
- retry scheduling/backoff;
- crash/resume after an ambiguous abort;
- local job terminal-state transitions;
- parser/OCR cancellation propagation.

Those durable execution concerns belong to M8.3 and later lifecycle qualification.
