## Boundary normalization contract

Accepted producer compatibility fields:

```text
accessZoneId      UUID?
accessZoneIds     UUID[]?
accessZoneCode    string?
accessZoneCodes   string[]?
ttlDays           integer? (default 0)
```

Rules:

1. Singular and plural aliases may coexist only when they identify the same single value.
2. Duplicate values in a plural alias collapse to one effective selector.
3. Multiple distinct IDs or multiple distinct codes are rejected.
4. ID and code may coexist. AstraIndexator preserves both as a correlation assertion; AstraVector resolves authority in M8.2+.
5. No selector is rejected.
6. AccessZone codes are strings, never integers.
7. `ttlDays` rejects booleans, floats, strings and negative integers.

## Migration safety correction

The initial M8.1 migration created the `requested_access_zone_selector_present` CHECK before backfilling existing rows. PostgreSQL validates a new CHECK against existing rows immediately, so any non-empty M1 database could fail the upgrade.

The qualified ordering is:

```text
add requested columns
→ add format constraints
→ backfill existing jobs
→ enforce requested selector presence
→ relax obsolete legacy code NOT NULL for UUID-only selectors
```

The same ordering is applied to prepared-artifact checkpoint lineage.

## Type-check qualification policy

The repository currently has pre-existing full-tree mypy debt outside the M8.1 change surface, including OCR, parser, normalization and optional third-party typing dependencies. Treating those unrelated errors as an M8.1 blocker would mix milestone qualification with a repository-wide typing remediation.

CI therefore uses two distinct checks:

1. `M8.1 scoped mypy` is a required gate over the M8.1 contract and persistence surface, including the coordinator claim contract.
2. `Baseline mypy debt report` runs against the whole `src/astra_indexator` tree with `continue-on-error: true`, so the debt remains visible and measurable rather than being hidden by global ignores.

The full-tree mypy gate should become blocking again only after a dedicated typing-remediation milestone reduces the baseline to zero.
