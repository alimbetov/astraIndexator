# M8.2.2 — LogicalBlock → generated protobuf mapper qualification

## Status

**M8.2.2:** IMPLEMENTED — CI QUALIFICATION PENDING

**Scope:** mapper qualification only. Transport, retry, durable delivery and reconciliation remain later M8.2/M8.3 work.

## 1. Authority

AstraIndexator maps application DTOs into Python protobuf messages generated from the pinned AstraVector contract:

```text
repository: alimbetov/llm2
proto: proto/astravector_embedding.proto
proto blob: ed1eab5f56dfb73cc48927ad2effb759a2c4e01e
```

Generation is performed by:

```text
tools/generate_astravector_proto.py
```

The mapper must not maintain a second wire DTO model.

## 2. Qualified mapping surface

`AstraVectorProtoMapper` maps:

```text
StartIngestionCommand
  -> StartLogicalDocumentIngestionRequest

AppendBlocksCommand
  -> AppendLogicalDocumentBlocksRequest

LogicalBlock
  -> LogicalBlock

SourceLocation
  -> SourceLocation

SourceLink
  -> SourceLink
```

M8.2.2 qualification specifically verifies nested `LogicalBlock` mapping and Start access-zone/TTL fields.

## 3. Invariants

The mapper must preserve these invariants before any wire call:

1. `access_zone_code` is a four-character ASCII digit string and `"0001"` remains `"0001"`;
2. at least one access-zone selector is present;
3. `document_version` is positive `uint32` for Start;
4. `total_blocks_estimate`, `total_pages_estimate`, `ttl_days`, `batch_index`, `LogicalBlock.order_index` and all numeric SourceLocation fields satisfy their protobuf ranges;
5. block and source-link enums map only to explicitly supported generated enum constants;
6. missing generated enum constants fail fast as contract-revision mismatch;
7. required block text, block id, source-link URL and idempotency key are non-blank;
8. `page_end >= page_start` and `char_end >= char_start` when both bounds are populated;
9. metadata and source-link attributes are copied into protobuf maps;
10. absent SourceLocation remains absent in protobuf rather than being synthesized;
11. the mapper instantiates the actual generated protobuf classes, not parallel DTO classes.

## 4. Qualification tests

Existing mapping logic tests:

```text
tests/test_m8_2_proto_mapper.py
```

They cover leading-zero AccessZoneCode preservation, UUID-only selectors, malformed selector rejection, integer overflow, nested LogicalBlock/SourceLocation/SourceLink mapping, unsupported enums, range ordering and generated-contract mismatch handling.

Generated-contract test:

```text
tests/test_m8_2_generated_proto_mapper.py
```

This test loads the generated client with `load_generated_client()` and proves that mapper output is an instance of the exact generated protobuf classes. It verifies:

- Start request preserves `access_zone_code="0001"` byte-for-byte;
- `ttl_days=0` remains `0`;
- content hash normalization is deterministic;
- LogicalBlock nested mapping uses generated enum constants;
- SourceLocation presence and values survive mapping;
- SourceLink enum, auth flag and attributes survive mapping.

## 5. CI correction required for real qualification

GitHub Actions jobs run on separate clean runners. Previously the pinned client was generated only in the quality job, while `pytest` ran in another job without generated files.

M8.2.2 therefore requires the test job itself to run:

```text
python tools/generate_astravector_proto.py
```

before `pytest`. This prevents generated-protobuf qualification from degenerating into a mock-only test.

## 7. Change control

Any change to these upstream or local surfaces invalidates M8.2.2 until re-qualified:

```text
llm2 proto LogicalBlock / SourceLocation / SourceLink
StartLogicalDocumentIngestionRequest
AppendLogicalDocumentBlocksRequest
BlockType enum
SourceLinkType enum
tools/generate_astravector_proto.py
AstraVectorProtoMapper
load_generated_client
```

Do not make generated protobuf optional in CI for this qualification gate.
